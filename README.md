# Jobbflyt

Mobilvennlig jobbsøkerdashboard uten innlogging. React, Vite, Recharts og lokal lagring.

## Kom i gang

```bash
npm install
npm run dev
```

Åpne adressen som vises i terminalen.

## Funksjoner

- Registrer, rediger og slett jobbsøknader
- Status, prioritet, frister, kontaktinfo og notater
- Filtrering og søk
- Dashboard med nøkkeltall og grafer
- Lokal lagring i nettleseren med JSON import/eksport

Data lagres på den aktuelle enheten, ikke i GitHub eller på en server. Ta regelmessig JSON-backup. Repository er offentlig: **ikke legg personlige søknadsdata i kildekoden.**
